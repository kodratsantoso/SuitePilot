## Phase Completion Criteria

A phase is considered complete when:

1. All deliverables listed in `ROADMAP.md` for that phase are done.
2. The SSOT files that cover the phase have been updated.
3. All new AI agents and skills introduced in the phase are registered in `AGENT_REGISTRY.md` and `SKILL_REGISTRY.md`.
4. The `CHANGELOG.md` records the phase completion.
5. Any architectural decisions made during the phase have ADRs.
6. At least one passing validation check exists for each major feature (starting Phase 1).

---

## Phase Transition Checklist

Before moving from one phase to the next:

- [ ] All tasks in `TASKS.md` for the current phase are marked complete
- [ ] No P0 or P1 bugs remain unresolved
- [ ] SSOT files are up to date
- [ ] CHANGELOG.md entry added
- [ ] Phase status updated in this file
- [ ] Next phase tasks added to `TASKS.md`
